# GO Web Crawler
Developed a CLI web crawler in Go that recursively crawls webpages, tracking and reporting the number of times each site is visited. Utilized Goroutines to manage concurrency and implemented input validation for configurable crawling parameters, including base URL, maximum concurrency, and maximum pages. Demonstrated proficiency in Go, recursion, and concurrency handling.
